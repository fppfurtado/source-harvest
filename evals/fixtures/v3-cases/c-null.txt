=== SOURCE S1 — "migrate-safe", a public collection of database-migration skills for coding agents (pasted) ===

README: migrate-safe packages three skills an agent can load while changing a production database schema.

skills/reversible-migrations/SKILL.md:
  Every migration ships with its down step, and CI applies up, down and up again before merge.

skills/expand-contract/SKILL.md:
  Rename or retype a column in three releases: add the new column and dual-write, backfill and switch
  reads, then drop the old column. Never rename in place.

skills/lock-timeouts/SKILL.md:
  Set a lock timeout on every DDL statement so a blocked migration fails fast instead of stalling traffic.
