# ux-check rubric

- **H1 Visible system status.** Every action that takes over 300 ms shows progress.
- **H2 Recognition over recall.** Filters and sort order stay visible; never hidden behind a menu.
- **H3 Touch targets.** Interactive elements are at least 44×44 px on touch screens.
- **H4 Destructive actions.** Deleting a route asks for confirmation and offers undo.
- **H5 Data-dense tables at narrow width.** A table wider than four columns collapses into stacked cards
  below 640 px, keeps the row's identifying column first, and never requires horizontal scrolling.
- **H6 Empty states.** An empty list explains why it is empty and offers the next action.
- **H7 Contrast.** Text meets WCAG AA contrast (4.5:1 body, 3:1 large).
